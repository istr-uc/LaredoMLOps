# Laredo

Laredo is a tool for creating, versioning, deploying, and monitoring machine learning pipelines on Kubernetes.

This site centralizes the operational documentation so it is easy to find the most important information: how to install it, how to use it, and how to change its configuration.

## Get started here

- [Installation](installation.md): steps to prepare the environment and deploy the project.
- [Usage](usage.md): basic workflow for operating the tool.
- [Configuration](configuration.md): reference for parameters in the `values.yaml` file.
- [Multimedia](multimedia.md): guide for adding images, screenshots, and video.
